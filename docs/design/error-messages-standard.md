# Estándar de mensajes de error

## Fórmula

Qué ocurrió + por qué importa + qué puede hacer el usuario.

## Ejemplo

No pudimos guardar la solicitud porque el servicio no respondió. Intenta nuevamente. Si continúa, reporta el folio.
