# Principios de diseño

1. Claridad antes que decoración.
2. Consistencia antes que creatividad aislada.
3. Accesibilidad desde el diseño.
4. Menos pasos para tareas frecuentes.
5. Retroalimentación visible.
6. Prevención de errores.
7. Interfaces responsivas.
8. Componentes reutilizables.
9. Contenido claro.
10. Seguridad y privacidad visibles cuando aporten confianza.
