# Guía de uso de la plantilla

## Propósito

Estandarizar la documentación, gobierno, seguridad, calidad, entrega y evidencia de proyectos de desarrollo de software.

## Cómo usar esta plantilla

1. Crear el repositorio desde la plantilla.
2. Completar los documentos iniciales.
3. Definir alcance, visión y contexto.
4. Crear SRS.
5. Definir arquitectura.
6. Configurar CI/CD.
7. Completar controles aplicables.
8. Mantener evidencia por release.

## Clasificación de documentos

| Nivel | Descripción |
|---|---|
| MUST | Obligatorio para todos los proyectos |
| SHOULD | Recomendado salvo justificación |
| CONDITIONAL | Aplica según características del proyecto |
| MAY | Opcional |

## Principios

- Documentación viva.
- Markdown portable.
- Seguridad por diseño.
- Accesibilidad por diseño.
- FOSS primero.
- Automatización antes que control manual.
- Evidencia por control.
