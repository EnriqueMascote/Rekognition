# SGSI Overview

## Propósito

Conectar el proyecto con controles, evidencias y mejora continua del Sistema de Gestión de Seguridad de la Información.

## Elementos

- Catálogo de controles.
- Declaración de aplicabilidad.
- Gestión de riesgos.
- Tratamiento de riesgos.
- Evidencias.
- Auditoría interna.
- Revisión por dirección.
- Mejora continua.
