# Metodología de evaluación de riesgos

## Escalas

| Valor | Probabilidad | Impacto |
|---|---|---|
| 1 | Baja | Bajo |
| 2 | Media | Medio |
| 3 | Alta | Alto |

Riesgo = Probabilidad x Impacto.
