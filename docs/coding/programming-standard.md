# Estándar de programación

## Principios

- Código claro sobre código ingenioso.
- Bajo acoplamiento.
- Alta cohesión.
- Validación explícita de entradas.
- Manejo consistente de errores.
- Logs útiles sin secretos.
- Dependencias mínimas y justificadas.
- Pruebas para lógica crítica.
