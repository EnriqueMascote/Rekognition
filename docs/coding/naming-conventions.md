# Convenciones de nombres

| Elemento | Convención |
|---|---|
| Variables | `camelCase` |
| Clases | `PascalCase` |
| Constantes | `UPPER_SNAKE_CASE` |
| Archivos frontend | `kebab-case` |
| Tablas SQL | `snake_case` plural |
| Columnas SQL | `snake_case` |
