# Política de accesibilidad

## Baseline

Todo sistema con interfaz de usuario debe cumplir WCAG 2.2 nivel AA como mínimo.

## Reglas

- Navegación por teclado.
- Contraste suficiente.
- Labels visibles.
- Mensajes de error accesibles.
- Foco visible.
- Semántica correcta.
- Pruebas automatizadas y revisión manual.
