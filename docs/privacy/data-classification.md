# Clasificación de datos

| Clasificación | Descripción | Ejemplo |
|---|---|---|
| Pública | Puede difundirse | Manual público |
| Interna | Uso institucional | Documentación interna |
| Confidencial | Acceso limitado | Datos operativos |
| Restringida | Alta sensibilidad | Secretos, datos personales sensibles |
