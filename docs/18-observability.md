# Observabilidad

## Baseline

- Logs estructurados.
- Métricas técnicas.
- Métricas de negocio.
- Trace ID / Correlation ID.
- Alertas accionables.
- Auditoría de eventos críticos.

## Prohibido registrar

- Contraseñas.
- Tokens.
- API keys.
- Datos personales innecesarios.
