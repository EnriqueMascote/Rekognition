# Obsidian

Obsidian puede usarse como cliente de navegación y edición, pero Git y Markdown son la fuente oficial.

## Reglas

- No depender de plugins para contenido crítico.
- Preferir enlaces Markdown estándar.
- Usar tags y frontmatter compatibles.
