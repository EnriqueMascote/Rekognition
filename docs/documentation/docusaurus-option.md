# Docusaurus

Docusaurus es alternativa avanzada cuando el proyecto requiere:

- portal público;
- MDX;
- React;
- blog;
- versionado fuerte de docs;
- sitio tipo producto.

La documentación normativa debe permanecer en Markdown portable.
