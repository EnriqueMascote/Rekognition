# Estándar de documentación

## Reglas

- Todo documento debe tener propósito.
- Todo documento debe tener responsable.
- Todo documento debe tener estado.
- Usar Markdown portable.
- Usar enlaces relativos.
- Evitar dependencias exclusivas de Obsidian.
