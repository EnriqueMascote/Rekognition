# Límites operativos para agentes

## Permitido

- Crear pruebas.
- Refactorizar dentro del alcance.
- Actualizar documentación relacionada.
- Proponer mejoras.

## Requiere aprobación

- Arquitectura.
- Seguridad.
- Base de datos productiva.
- Dependencias nuevas.
- CI/CD.
- Permisos.

## Prohibido

- Subir secretos.
- Deshabilitar pruebas.
- Eliminar logs de auditoría.
